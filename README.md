# Interior-design
Interior Design Web Project using PHP and MySQL. Includes database, book listings, and cart system for managing interior design models.
  # Interior Design Web Project

A simple **Interior Design Web Application** built using **PHP and MySQL**.
This project allows users to browse interior design models/books and add them to a cart.

## 🚀 Features

* View interior design items
* Display models/books with images
* Add items to cart
* Store cart data in MySQL database
* Simple and beginner-friendly PHP project

## 🛠 Technologies Used

* PHP
* MySQL
* HTML
* CSS
* JavaScript
* XAMPP / Localhost server

## 🗄 Database

Database Name: `int_design`

Tables used:

* `books` – Stores interior design book/model details
* `cart` – Stores items added to cart by users

Database file:

```
db/int_design.sql
```

## ⚙️ How to Run the Project

### 1. Clone the repository

```
git clone https://github.com/Sarthaksinghal00/Interior-design.git
```

### 2. Move the project folder

Move it to your server directory:

Example (XAMPP):

```
xampp/htdocs/
```

### 3. Import the database

Open **phpMyAdmin**

Create database:

```
int_design
```

Import:

```
db/int_design.sql
```

### 4. Start the server

Start:

* Apache
* MySQL

### 5. Open in browser

```
http://localhost/Interior-design
```
